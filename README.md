PlanAhead is a ASP.NET CORE MVC Project (Event Management System)

This Project is developed in Asp.net MVC Core 1.0.0 with windows dependencies.

About Platform Used

I had developed this Application using Microsoft Visual Studio Community 2022 with Microsoft SQL server 2016. Server-side Technology used is ASP.NET Core MVC 1.0 and Language used for developing in C#, along with this Entity Framework Core and Dependency Injection for database accessing and finally for using Services we have Used Web API.

The main functions of our application are can be divided in 3 different parts:  
• Student module  
• Department module  
• Admin module  

Student module  
• View entire college events 
• Login to the Page  
• Register and remove the event  
• View results  
• View department information  
Admin module  
• Login to the Page  
• Add response to the events  
• View entire college events 
• Approve events  
• View reports  
Department module  
• Login to the Page.  
• Create event  
• View registered students 
• Remove events 
• Submit Report  

Backend: C#, ASP.NET MVC, Entity Framework

Frontend: HTML, CSS, Bootstrap, javascript
